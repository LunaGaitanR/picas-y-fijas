# 🎯 Picas y Fijas

## Descripción

Picas y Fijas es un juego de lógica y deducción numérica en el que los jugadores deben descubrir un número secreto de cuatro cifras, sin dígitos repetidos.

El proyecto contará con dos modalidades de juego:

- **Contra el sistema:** la computadora genera un número secreto y el jugador debe adivinarlo.
- **Dos jugadores:** un jugador establece el número secreto y el otro intenta descubrirlo.

## Reglas del juego

- El número secreto tiene cuatro cifras.
- No se permiten dígitos repetidos.
- Una **pica** indica que un dígito está en el número secreto, pero en una posición diferente.
- Una **fija** indica que un dígito está en el número secreto y en la posición correcta.
- El objetivo es conseguir cuatro fijas.

## Objetivo del proyecto

Desarrollar una aplicación funcional que permita jugar Picas y Fijas en sus dos modalidades, aplicando buenas prácticas de programación, control de versiones, pruebas de software, integración continua y despliegue.
